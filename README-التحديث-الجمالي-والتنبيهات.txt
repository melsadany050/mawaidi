مواعيدي العائلية – النسخة المحسّنة بصريًا والمتوافقة مع الهاتف

ما تم تعديله:
- تحديث لوحة الألوان إلى أخضر هادئ وخلفية فاتحة متناسقة.
- تحسين بطاقات المواعيد وتأثير التمييز عند مرور الماوس أو التركيز/اللمس.
- تخصيص لون ثابت لكل فرد اعتمادًا على معرّف حسابه، حتى لا يتغير اللون بتغير ترتيب عرض الأفراد.
- إضافة إعداد محلي لاختيار التذكير قبل الموعد: إيقاف، 5، 10، 15، 30، 60 دقيقة.
- إضافة زر لطلب إذن إشعارات الجهاز.
- تحديث ألوان PWA ورقم ذاكرة التخزين المؤقت لتحديث النسخة الجديدة.

ملاحظات مهمة:
- حافظت النسخة على Firebase Authentication وFirestore وقواعد البيانات الموجودة في المشروع.
- لم يتم تغيير قواعد Firestore أو نقل/حذف بيانات الأسرة.
- إعداد مدة التنبيه محفوظ على الجهاز/المتصفح نفسه، ويجب ضبطه على كل جهاز على حدة.
- التذكيرات الحالية تعمل عندما تكون صفحة التطبيق مفتوحة ويكون المتصفح قد منح إذن الإشعارات. لا تعتبر هذه النسخة إشعارات خلفية مضمونة بعد إغلاق التطبيق؛ ذلك يحتاج إعداد Web Push وخادم إرسال/جدولة واختبارًا إضافيًا.
- لا حاجة إلى إعادة نشر قواعد Firestore بسبب هذه التعديلات.
- افتح التطبيق عبر HTTPS أو localhost، وليس بفتح ملف index.html مباشرة.

التشغيل المحلي:
1) فك ضغط الملف.
2) افتح CMD داخل المجلد الذي يحتوي على index.html.
3) نفّذ: py -m http.server 8083
4) افتح: http://localhost:8083
5) سجّل الدخول بنفس حساب الأسرة الحالي.

ملفات الواجهة الرئيسية ونسخة www محدثة معًا.
